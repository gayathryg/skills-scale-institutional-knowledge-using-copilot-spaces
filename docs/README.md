# OctoAcme Project Management Docs

## Overview

This is the central entry point for OctoAcme’s project management practices and process documentation. These living docs make it easy for anyone on the team to find, understand, and follow our core project management approach—helping us deliver reliably, onboard quickly, and improve as we go.

## How We Manage Projects

Our process is:
- **Customer-first.** We prioritize user value, measure outcomes, and deliver what matters most.
- **Iterative.** Small, testable increments with frequent feedback and learning.
- **Clear Ownership.** Each project has a PM and Product Lead.
- **Data-Informed.** We track key metrics and improve based on evidence.
- **Safe for Feedback.** Transparent communication and blameless retrospectives are standard.

### Core Project Lifecycle

1. **Initiation:** Validate the need, define success metrics, align stakeholders.
2. **Planning:** Break down work, estimate, identify risks and dependencies.
3. **Execution:** Use boards, standups, and regular demos; escalate and resolve blockers quickly.
4. **Release & Deployment:** Documented playbooks and checklists for safe, observable launches.
5. **Retrospective:** Capture learnings and drive continuous improvement for future work.

### Core Roles

- **Project Manager:** Delivery, coordination, schedules, risk.
- **Product Manager:** Vision, prioritization, success metrics.
- **Developers:** Implement, test, and document.
- **QA/Testing:** Validate releases and acceptance.
- **Stakeholders:** Input, approvals, unblock at milestones.
